# CleanSheet_VBA_BETA

**Text & Format (8 features)**
    UPPERCASE / lowercase / Proper Case: Convert selected text instantly
    Text ↔ Numbers: Convert between text and numeric formats (handles "1,234" ↔ 1234)
    Add Prefix/Suffix: Bulk add text before/after cell values
    Leading Zeros: Convert numbers to text with padding (e.g., 123 → "000123")
**Duplicates (3 features)**
    Delete Duplicates: Remove duplicate rows with automatic backup
    Color Duplicates: Highlight duplicate values visually
    Count Values: Search and count specific values with summary table
**Sheets & Index (4 features)
    Sort Sheets A-Z: Alphabetically organize worksheet tabs
    Create Index: Generate clickable sheet index with hyperlinks
    Update Index: Refresh existing index with timestamp
    Remove Empty Sheets: Delete sheets with no data/objects
**Colors & Audit (4 features)**
    Color Numbers: Highlight numeric cells (light blue)
    Color Text: Highlight text cells (light green)
    Color Formulas: Highlight formula cells (light yellow)
    Color Comments: Highlight cells with comments (light orange)
